# Contributing

This repository is a read-only mirror of Render's internal source of truth. Pull requests opened against it will be closed.

To report a bug or request a change, [open an issue](https://github.com/render-oss/render-mcp-server/issues). We'll make the fix internally, and it will appear here on the next sync.

To report a security vulnerability, see [SECURITY.md](SECURITY.md).
